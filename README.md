# App portfolio of Thabiso

**View the page: [carefulcamel61097.github.io/app-portfolio](https://carefulcamel61097.github.io/app-portfolio/)** (work in progress)

A one-page site showing my apps (SportsPort, ConvoGo, Zouzou) and how I build with AI.

- `index.html` has all the content. Placeholder text is wrapped in `<mark class="todo">...</mark>` and shows highlighted. Add `class="no-todo"` to `<body>` to preview without highlights.
- `styles.css` and `script.js` handle the layout, the folder tabs and the light/dark switch. Link to a specific app with `#sportsport`, `#convogo` or `#zouzou`.
- `assets/` holds the app icons and screenshots.
- `AI_TELLS.md` lists things that make a page look AI-made, so we can avoid them.

Open `index.html` in a browser to preview. There's no build step. Pushing to `main` updates the live page.
