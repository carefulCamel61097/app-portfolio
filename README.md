# App portfolio — Thabiso

**➜ View the page: [carefulcamel61097.github.io/app-portfolio](https://carefulcamel61097.github.io/app-portfolio/)** *(work in progress)*

Static one-page site showing my apps (SportsPort, ConvoGo, Zouzou) and how I build with AI.

- `index.html` — all content. Placeholder text is wrapped in `<mark class="todo">…</mark>` (highlighted). Add `class="no-todo"` to `<body>` to preview without highlights.
- `styles.css`, `script.js` — layout and the folder-tab behaviour. Link to a specific app with `#sportsport`, `#convogo` or `#zouzou`.
- `assets/` — app icons and screenshots.

Open `index.html` in a browser to preview. No build step. Pushing to `main` updates the live page.
